MUSIC CREATOR

伝えたい言葉を、鳴る1曲に。

Claude が書き、Gemini が磨き、Suno が鳴らす。
音楽心理学の知見をもとに、Suno にそのまま貼れる形で仕上げます。

制作の流れ

STEP 1 Gemini任意

参考曲・歌詞の学習

好きな曲と歌詞から「定番」と「書き方の傾向」を学ばせます。
ここで学習した内容は、STEP 2〜5 の作詞と推敲に反映されます。

APIキーなしで使う
  2. Gemini アプリに貼って送信し、返ってきた JSON を下に貼る

評価から好みを学習する

STEP 4 で曲に★を付けておくと、高評価と低評価の曲を比べて「しょーまさんの好み」を学習し、 次の作詞と Style に反映します。★を付けた曲が3曲以上(高評価と低評価の両方があると精度が上がります)で使えます。

APIキーなしで使う:返答を読み込む

歌詞を学習させる

自分の過去の歌詞や手本にしたい歌詞を取り込むと、行の長さ・言葉の詰め方・繰り返し方・韻・人称などの 「書き方の傾向」を学習します(歌詞の文言そのものは使いません)。
歌詞はこのブラウザの中だけに保存され、学習するときだけ Gemini に送られます。目安は3曲以上です。

        作品と履歴

        作った曲は、このブラウザに最大100件まで保存されます。推敲や修正をするたびに、版(v1, v2…)が増えます。

        アルバム設計

        同じプロジェクトの曲(各曲の最新版)をまとめて見て、曲順・偏り・似すぎている所・統一感を出す Style を提案します。2曲以上で使えます。

        APIキーなしで使う:返答を読み込む

        友達の反応

        友達に送った共有リンクから届いた「回答コード」(MCV1. で始まる文字)を貼り付けて読み込みます。 何人分でもまとめて貼れます。結果は好みの学習とアルバム設計にも使われます。

        バックアップ・別の端末へ移す

        曲・履歴・参考曲・学習結果・評価をファイルに書き出し、別の端末やブラウザで読み込めます。 データは端末ごとに別々に保存されるため、パソコンとスマホで使うときはこの方法で移してください。 APIキーは書き出しません。

        ナレッジ

        AI への指示に毎回組み込んでいる知識です。研究は「傾向」を示すもので、必ずヒットする法則ではありません。

        設定

        API キーは、このブラウザの中にだけ保存されます(各 AI 会社の API 以外へは送信しません)。
        キーがなくても、各画面の「APIキーなしで使う」から claude.ai や Gemini アプリにコピペして使えます。

        AI の使用量

        Claude の料金は Anthropic 公式の単価(Opus 5.5:100万トークンあたり入力 $4・出力 $20)から計算した目安です。正確な請求額は各社の管理画面で確認してください。

        スマホのホーム画面に追加する

        • iPhone(Safari):共有ボタン → 「ホーム画面に追加」
        • Android(Chrome):メニュー → 「アプリをインストール」または「ホーム画面に追加」
        • 追加すると、アプリのように全画面で開けます。電波が弱くても、画面・履歴・教科書は開けます(AI での生成には通信が必要です)。
        • Claude の API キー:Claude Console で発行
        • Gemini の API キー:Google AI Studio で発行
        • モデル名は新しいものが出たら書き換えてください。
        • 共用のパソコンでは、使い終わったら「キーを削除」を押してください。
