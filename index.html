Music Creator

伝えたいメッセージを、Suno にそのまま貼れる1曲に。

📘 使い方の教科書

① メッセージから作る Claude

伝えたいことを書くだけで、歌詞と Suno 用の Style を作ります。
おすすめは「Aメロ+サビを量産」→ 気に入った案を「フル尺に仕上げる」の流れです。

キーなしで使う:claude.ai の返答を貼り付けて読み込む
  1. 上の「キーなし」ボタンでプロンプトをコピー
  2. claude.ai に貼り付けて送信
  3. 返ってきた JSON を下に貼り、「読み込む」を押す

② 歌詞を補強 Gemini

できている歌詞を磨き上げ、Suno 用の Style プロンプトを作ります。
視点のブレや、テーマ用語の詰め込みも直します。

キーなしで使う:Gemini の返答を貼り付けて読み込む
  1. 「キーなし」ボタンでプロンプトをコピー
  2. Gemini に貼り付けて送信
  3. 返ってきた JSON を下に貼り、「読み込む」を押す

③ サンプル楽曲の要素を抽出 Gemini

参考にしたい曲の「その曲らしさ」を分解し、Suno 用の Style に変換します。
音声ファイル・YouTube の URL・曲名のどれか1つでOKです。

キーなしで使う:Gemini の返答を貼り付けて読み込む

Gemini アプリに音声ファイルや YouTube の URL を一緒に渡してから、コピーしたプロンプトを送ってください。

④ Suno に貼る

Suno の「Custom」モードの各欄に、そのままコピーして貼ってください。
ここで直接書き換えることもできます。
